# SOFI'S LIBRARY
A terminal-based library management system developed in C++. The library allows users to view available books, add new books, borrow books, and return borrowed books. All book data is stored in a text file (.txt), which is loaded when the program starts and automatically saved when the program exits.

## Features 
1. Add a new book
2. Borrow book
3. Return book
4. View available books
5. Exit the program
